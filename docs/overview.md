# Overview

Our lab objectives today are to configure a Catalyst SD-WAN based network with two Data Centers and three Branch site.
Then you will deploy ThousandEyes Agents to all the routers and validate that they are communicating to the ThousandEyes dashboard.
From there, you will implement the NGFW on the routers and test that the IPS functionality is working to block the intended signatures.
Finally, you will integrate Secure Access into the Catalyst SD-WAN environment and redirect client traffic from the DIA configuration to the Secure Access tunnels.
