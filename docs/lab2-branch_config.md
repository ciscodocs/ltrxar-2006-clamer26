# Lab 2: Branch Site Topology Configuration

## Task 1: Single Router Branches

1. Download the ![lab start-up import file](https://github.com/CiscoLearning/ciscolive-ltrxar-2006/blob/main/sdwan_files/startup/export-2026-05-28T14_36_33.tar.gz) to your local desktop.

    !!! note
        You must **right-click** on the link above and click **Save** or **Save Link As** in your browser to download the configuration export. 

2. In Cisco Catalyst SD-WAN Manager, click **Configuration** then **Configuration Groups** to open the Configuration Group context.
3. In the top navigation bar, click **Import** to open the file upload context.

    ??? tip "Step Help"
        <img src="../assets/images/lab02/task01/step-03_import-group.png" alt="Import configuration group template link" width="300px">

4. In the file upload context, navigate to the directory where you saved the downloaded file from Step 1. Select the file **`something.tar.gz`**, and click **Open** to import the Configuration Group.
5. Verify the import was successful. If errors are encountered, notify your proctor for assistance.

## NOTE - This should be lab init. Just create an export of a Config Group (or more than one) with the necessary profiles. Prefix them like "zzz_legacy_unused" or whatever.
